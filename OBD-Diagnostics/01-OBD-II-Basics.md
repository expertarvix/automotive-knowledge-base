# OBD-II Basics

## What is OBD-II?

OBD-II (On-Board Diagnostics II) is a standardized vehicle diagnostic system that monitors various systems and components of a vehicle.

## What does OBD-II monitor?

OBD-II can monitor systems such as:

- Engine
- Emission control
- Fuel system
- Ignition system
- Sensors
- ECU-related functions

## What is a DTC?

DTC stands for Diagnostic Trouble Code.

When the vehicle's ECU detects an abnormal condition, it may store a DTC.

Example:

P0300 — Random/Multiple Cylinder Misfire Detected

## Important Point

A DTC does not always mean that the component named by the code is faulty.

Proper diagnosis requires:

1. Reading the DTC
2. Checking symptoms
3. Checking live data
4. Testing the related circuit/component
5. Finding the root cause
6. Verifying the repair

## Diagnostic Principle

Never replace a component only because a fault code points toward it.

Always confirm the root cause before replacing parts.
